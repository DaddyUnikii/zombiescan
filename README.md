# 🧟 zombiescan

**Find the token approvals your wallet still gives to ghosts.**

</div>

Dead contracts, empty proxies and forgotten routers can still hold the keys to your tokens.
`zombiescan` finds every live ERC-20 / ERC-721 / ERC-1155 approval on a wallet and checks whether
anything is really alive behind the spender.

> 🚧 Work in progress. The scanner lands in the next pull requests.
